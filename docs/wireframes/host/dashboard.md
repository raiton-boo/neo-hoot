# ホスト: クイズ一覧画面 (`dashboard.html`)

## 共通ヘッダーの導入

ログイン前（`login.html`）の巨大な「neo-hoot」ロゴ（`h1`, 2.5rem）と、ログイン後の画面見出しが同じ見た目だと、内部ページなのに毎回ランディングページのような印象になってしまう（違和感の原因だった）。これを解消するため、ログイン後の管理画面系には**小さめの共通ヘッダー**（`.app-header`: ロゴ＋ユーザーメニュー）を導入し、ページごとの見出し（「クイズ一覧」等）は通常サイズにする。

どの画面に共通ヘッダーを入れるかの方針は`docs/design.md`を参照（管理画面系のみ、ライブ進行画面には入れない）。

## 見出しの命名

「マイクイズ」は却下し、「クイズ一覧」に変更した。より落ち着いた命名。

## 「＋ 新しいクイズを作成」の重複を解消

見出し横のボタンと、カード一覧末尾の「追加」タイル（半透明で分かりにくかった）が重複していたため、見出し横のボタン1つに統一した。

## クイズカードのグリッド幅

`grid-template-columns: repeat(auto-fill, minmax(220px, 1fr))`の`220px`だと、カード内の「開催回数」バッジと「開催する」ボタンが横に並びきらずレイアウトが崩れていた。`320px`に広げて解消した。

## ユーザーメニュー

アバター＋名前＋シェブロン（▼）アイコンをまとめて1つのクリック可能なボタンにする（`.app-header .user-menu`）。**PC/スマートフォンでの実際の開き方（ドロップダウン/ボトムシート等）は未確定**、実装フェーズで決める（TODO）。
