# 参加者: ルーム参加画面 (`join.html`)

## 参加⇔ホスト切り替え

- 見出し直下に「参加する」／「ホストの方はこちら」の目立つタブ状の切り替えを置く（`.mode-switch`）。右上の小さいテキストリンクよりも発見しやすい場所にする。
- 今いる方のタブをハイライト表示する（`.mode-switch a.active`）。
- ページ表示時にカードがふわっと下から浮き上がるアニメーションを付ける（`.enter-animate`）。**本実装では`Framer Motion`の`AnimatePresence`を使い、タブ切り替え時にもっと滑らかな遷移（クロスフェードやスライド）にする**（TODO）。

## QRコードスキャンボタン

- 単なる四角いボタンではなく、カメラのビューファインダー風の四隅ブラケットをアイコン部分に描き、「スキャンする」ことが視覚的に伝わるようにする（`.qr-viewfinder` + `.corner`）。
- 枠線は点線ではなく、他のボタンと同じ「実線＋オフセット影」で統一する。点線（＝平らな読み取りエリアを連想させる）と浮き上がった影（＝立体的なボタンを連想させる）が視覚的に矛盾するため。

## QRコードの読み取り方法による挙動の違い

- **外部（OSのカメラアプリ等）で読み取った場合**: URLに`?room=xxxx`が付いた状態でブラウザが新規にページを開く。ページ読み込み時にクエリパラメータからルームコードを取得し、入力欄に自動反映する（実装済み、`URLSearchParams`で取得）。
- **サイト内（この画面の「QRコードをスキャン」ボタン）で読み取った場合**: ページ遷移・リロードを伴わず、カメラ映像をその場（モーダル等）で表示し、読み取り結果を直接JavaScriptで入力欄に反映する想定（未実装、実装フェーズで対応）。ページ遷移が発生しない分、より滑らかな体験にする。
