# ホスト: ログイン画面 (`login.html`)

## サインアップとログインを分けない

OAuthのみの認証では、新規登録とログインを別のフォームに分ける必要がない。ボタンを押した結果、裏側で「初めての人なら自動でアカウント作成、既存の人ならログイン」という判定をサーバー側が自動で行うため（`docs/architecture.md`の認証フロー参照）。ボタンの文言も「Googleでログイン」ではなく「Googleで始める」とし、初回/2回目以降を区別しない。

## OAuthボタンは各サービスの公式配色に寄せる

自社のネオブルータリズム配色（黄色×太枠）に染めず、Googleは白背景＋公式ロゴ、GitHubは黒背景＋Octocatマークと、各サービスの一般的なデザインに寄せる。理由は、OAuthボタンがユーザーにとって「本当にGoogle/GitHubに飛ぶ、偽物ではない」という信頼の手がかりでもあるため。枠線・影（オフセットシャドウ）は自社デザインと共通の言語として残す。

## 参加者導線

`participant/join.html`と同じ`.mode-switch`タブを使い、「参加する」への切り替えを見出し直下に配置する（詳細は`docs/wireframes/participant/join.md`参照）。
