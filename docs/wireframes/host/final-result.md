# ホスト: 最終結果画面 (`final-result.html`)

プロジェクター等に投影する、ライブ進行画面の1つ。共通ヘッダーは含まない（`docs/design.md`の方針）。

## 表彰台の配色（金銀銅）

`docs/design.md`の「グラデーション・半透明は使わない、ベタ塗りのみ」というルールと、「順位を光沢感で見分けやすくしたい」という要望を両立させるため、**グラデーションは使わず、フラットな金・銀・銅色をベタ塗りで使う**方針にした（このページ専用の変数として`--color-gold`, `--color-silver`, `--color-bronze`を定義。UI全体の共通パレットには追加しない）。

- 金は既存の`--color-primary`（黄色）を流用。銀・銅はこの画面専用に新規追加。
- 3位（銅色）のメダルは、当初白文字にしていたが、コントラスト比を計算すると黒文字（比率6.39）の方が白文字（比率3.15、WCAG AAの4.5を下回る）より読みやすいことが分かり、黒文字に修正した。
- 1位には👑（王冠の絵文字）を追加。

## 全体順位リスト

表彰台（1〜3位）だけでは4位以下の参加者が自分の順位を確認できないため、その下に4位以降のリストを追加した。

- **表示は10位までに制限する**。人数が多いホストの場合に画面が間延びするのを防ぐため。11位以降は表示しない（`「11位以下は表示されません」`の注記を出す）。
- 長い名前は`docs/design.md`の「テキストの省略ルール」に従い、`...`で省略し`title`属性でフルネームを保持する。

## ボタンの優先度

「もう一度開催する」と「クイズ一覧に戻る」を同じ強さのボタンとして並べていたが、ホストが次に取る行動として自然なのは前者のため、優先度を分けた。

- **もう一度開催する**: 大きく、明確なボタンとして中央に配置
- **クイズ一覧に戻る**: 下線付きのテキストリンクに近い、控えめな見た目

## 同点者がいる場合の順位の扱い（TODO: 実装フェーズで多人数対応のUIを作る）

採点方式が「正解＋回答速度」のため上位での同点は起きにくいが、**全問不正解（0点）の参加者が複数いる場合など、下位での同点は普通に起こりうる**。以下の方針とする。

1. **順位番号のルール**: 標準的な競技順位方式を採用する。同点者は同じ順位番号になり、次の順位は同点者数の分だけスキップする（例: 100, 90, 90, 80点 → 1位, 2位, 2位, 4位。3位は欠番）。
2. **表彰台（トップ3）の表示**: 同点によりトップ3の対象人数が変わる場合（例: 2位が2人いる）、該当する順位のブロックに**複数名をまとめて表示する**。メダルの色は順位（1位=金, 2位=銀, 3位=銅）にそのまま対応させる。
3. **現在のワイヤーフレームは3人が完全に分かれているケースのみを表現している**。1つの順位ブロックに複数名が入るレイアウト（幅の可変対応など）は、実装フェーズで別途デザインする。
