# ホスト: アーカイブ済みクイズ画面 (`archived-quizzes.html`)

## 位置づけ

`dashboard.html`の見出し横「🗄 アーカイブ済みを見る」から遷移する、独立したページ。詳しい経緯は`docs/wireframes/host/dashboard.md`の「アーカイブ済み一覧は別ページにする」を参照。

## できること

- アーカイブ済みのクイズだけを一覧表示する（並び順はアーカイブした日時が新しい順を想定）
- **復元する**: アーカイブを解除し、`dashboard.html`の一覧に戻す
- **完全に削除する**: 一度も開催していないクイズにだけ実際に成功する。開催履歴があるクイズに対して実行した場合、APIが409エラーを返すので、その場でエラーメッセージを表示する想定（TODO: 実装フェーズでトースト等のエラー表示方法を決める）

## デザイン

`dashboard.html`のクイズカードとほぼ同じ見た目だが、`opacity: 0.7`で少し色を落とし、「今は使っていないクイズ」であることを一目で分かるようにしている。「⋮」メニューは無く、「復元する」「完全に削除する」の2つのボタンを`.meta`内に直接並べている（普段使う一覧より操作の種類が少なく、隠す必要が無いため）。
