# ホスト: クイズ編集画面 (`quiz-editor.html`)

## 編集の操作方法（アコーディオン方式）

設問一覧の中の1問をクリックすると、その場（本来の並び順の位置）で編集フォームに展開される。他の設問は折りたたまれた要約行のまま。

- 当初、編集中の設問（Q2）が一覧から消えて別の場所に浮いたカードとして表示されており、一覧との繋がりが分かりにくかった。Q1〜Q4の並び順の中にQ2をそのまま展開する形に修正した。
- 折りたたまれた行には、鉛筆アイコンの編集ボタンを追加し、クリックできることを明示する（`.edit-icon-btn`）。他のボタンと同じ「太枠＋影＋押下時の沈み込み」で統一し、はっきりとボタンだと分かるようにする。

## 設問タイプの一覧バッジ

「4択」「○×」「アンケート」の一覧バッジは、全て同じ見た目（通常の黄色バッジ）に統一する。以前は「アンケート」だけ青色にしていたが、これは意図的なルールではなく統一漏れのミスだった。

## 設問タイプ切り替えタブの配色

編集フォーム内の「4択／○×／アンケート」切り替えタブは、選択中＝黄色、非選択＝**枠線のみの中立色**にする（`.type-tabs .btn.inactive`）。以前は非選択をピンク（`.btn-secondary`）にしていたが、ピンクは4択の回答画面で「選択肢A」の色としても使っているため、「非選択」という意味と衝突していた。
