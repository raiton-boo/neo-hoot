# 📋 機能仕様書 (neo-hoot)

## 1. サービス概要

Kahoot!風のリアルタイム・クイズ＆アンケートプラットフォーム。ホストが作成したクイズを使ってライブセッションを開催し、参加者がスマートフォンからリアルタイムに回答する。

## 2. ユーザー種別

| 種別       | アカウント               | 主な操作                                         |
| :--------- | :----------------------- | :----------------------------------------------- |
| **ホスト** | 必須（OAuthログイン）    | クイズの作成・編集・保存、ルームの開催、進行操作 |
| **参加者** | 不要（ニックネームのみ） | ルームコードで参加、出題への回答                 |

参加者はアカウント作成の手間なく、その場でニックネームを入力するだけで参加できるようにする（Kahoot本家と同じ設計思想）。

## 3. データの2層構造

- **クイズ（Quiz）**: ホストが事前に作成する「設問セットのテンプレート」。1度作れば繰り返し使い回せる。
- **ルーム / ゲームセッション（Room / GameSession）**: あるクイズを実際に「開催した1回分」の記録。参加者・回答・スコアはすべてこのセッションに紐づく。

同じクイズから何度でもルームを開催でき、過去の開催結果もセッションごとに履歴として残る。

## 4. 出題形式

| 形式       | 説明                                                            | 正解の有無 |
| :--------- | :-------------------------------------------------------------- | :--------- |
| 4択クイズ  | 4つの選択肢から1つを選ぶ                                        | あり       |
| ○×クイズ   | 2択（Yes/No, ○/×）                                              | あり       |
| アンケート | 複数の選択肢から1つを選ぶが、正解・不正解の概念がない意見収集用 | なし       |

1つのクイズの中に、上記3形式の設問を自由に混在させられる。

## 5. 採点方式

- **正解 + 回答速度でスコアリング**（Kahoot式）。同じ正解でも、早く回答するほど高得点。
- アンケート形式の設問はスコア加算の対象外（集計結果の表示のみ）。
- 各設問終了時に「その設問時点でのランキング（上位者）」を表示する。
- 全設問終了後に最終ランキングを表示する。

## 6. ゲーム進行フロー

1. ホストがクイズを選び、ルームを開催する（ルームコードが発行される）
2. 参加者がルームコードを入力し、ニックネームを設定して参加する（ロビー画面で待機）
3. ホストが「開始」を押すと、設問が全員の画面に表示される
4. 参加者は制限時間内に回答を送信する
5. 制限時間終了後、正解発表・回答分布・その時点のランキングを表示する
6. 3〜5を設問の数だけ繰り返す
7. 全設問終了後、最終ランキングを表示してセッション終了

## 7. 画面一覧（詳細はデザインフェーズで確定）

### ホスト側（PC想定）

- ログイン画面
- ダッシュボード（作成したクイズの一覧）
- クイズ作成・編集画面
- ルーム開催前のロビー画面（ルームコード表示、参加者一覧）
- 出題進行画面（設問・タイマー・回答状況）
- 設問ごとの結果発表画面（正解・回答分布・途中ランキング）
- 最終結果画面

### 参加者側（スマートフォン想定）

- ルーム参加画面（ルームコード入力、またはQRコード読み取り＋ニックネーム入力）
- ロビー待機画面
- 回答画面（選択肢を選んで送信）
- 個人結果画面（正解・不正解、獲得ポイント）
- 最終順位画面

## 8. 今回のスコープ外（将来的な拡張候補）

- チーム戦モード
- 参加者アカウント・回答履歴の永続化
- クイズの公開共有・他ユーザーによる複製
