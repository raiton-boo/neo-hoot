# 参加者: 回答画面 (`answer-choice.html` / `answer-truefalse.html` / `answer-survey.html`)

出題形式（4択・○×・アンケート）ごとに画面を分けている（`docs/spec.md`の出題形式に対応）。

## 4択 (`answer-choice.html`)

- 選択肢ボタンは`aspect-ratio: 1`で正方形に固定する（`.choice-btn`）。
  - 当初、ボタンを含む`.choice-grid`に`flex: 1`を指定しており、画面の余った縦スペースを埋めようとしてボタンが縦に間延びしていた。正方形固定で解消した。
- 2行×2列のレイアウトのため、スマートフォンの縦長画面でも自然に縦方向のスペースを使え、追加の対応は不要だった。

## ○× (`answer-truefalse.html`)

- 選択肢が2つしかないため、4択と同じ「横並びの正方形」だとスマートフォンの縦長画面で下に余白が目立ってしまう。
- **レスポンシブ対応**: 画面幅480px以下（スマートフォン想定）では、2つのボタンを**縦積みの横長ボタン**に切り替える（`@media (max-width: 480px)`）。iPad等の広い画面では横並びの正方形のまま。
- 色は緑（○/true）・赤（×/false）の直感的な対応にする。

## アンケート (`answer-survey.html`)

- 選択肢の数が可変（4択のように固定4つではない）ため、グリッドではなく**縦積みのリスト**にする（`.survey-list`）。
- 正解・不正解の概念がないため、選択肢の色は**中立色**（白背景・枠線のみ）にする。緑・赤・4択の色分けを使うと「正解がある」ように誤解されるため、あえて色分けしない。
