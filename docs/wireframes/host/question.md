# ホスト: 出題進行画面 (`question.html`)

プロジェクター等に投影する、ライブ進行画面の1つ。共通ヘッダーは含まない。

## ヘッダーのバッジ

- 「第2問/全5問」「回答済み」の2つは、離れた四隅ではなく、**タイマーを挟んで中央にまとめて配置**する。プロジェクター視聴時、視線が集まる中央から離れた隅は見落とされやすいため。
- 見た目は白背景（`--color-surface`）の枠付きピル型バッジに統一する。絵文字は付けない（文字だけで十分に読み取れるため、装飾過多を避ける）。
- 「回答済み」バッジは文字のみとする。プログレスバーを添える案も試したが、同じ画面にタイマーがすでにあり情報過多になるため、シンプルな文字表示に戻した。

## タイマーの緊急演出

残り時間が5秒以下になったら、タイマーの背景を赤（`--color-danger`）に変える。残り時間が少ないという緊張感を演出する。

## 設問数の視覚化

「第2問/全5問」というテキストに加えて、`●●○○○`のようなドット表示を添え、進み具合を一目で分かるようにする。

## 選択肢の登場アニメーション

設問が切り替わった瞬間、4つの選択肢を同時にではなく、時間差（0.1秒刻み）でポップインさせる。

## 制限時間が0秒になったときの挙動（TODO: 実装フェーズで詳細確認）

1. **参加者側**: 0秒になった瞬間、回答ボタンを即座に無効化する。以降の回答送信は受け付けない。
2. **未回答の参加者**: その設問については0点として扱う（`docs/architecture.md`の採点ロジックに従う）。
3. **ホスト側の画面遷移**: 0秒になったら、短い間（1秒程度）を置いてから自動的に`question-result.html`（設問結果画面）へ遷移する。集計処理の完了を待つための間。ホストが手動で「次へ」を押す必要はない（「次の設問へ」の操作が必要になるのは、結果発表後、次の設問に進むタイミングのみ）。
